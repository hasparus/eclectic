# Paidotopos

Personal prototype playground in the eclectic Bun workspace. Next.js App Router, TypeScript, Tailwind v4, full shadcn/ui registry, next-themes, Playwright.

From repository root:

```sh
bun install
bun run --cwd packages/paidotopos dev
```

## Checks

```sh
bun run --cwd packages/paidotopos lint
bun run --cwd packages/paidotopos typecheck
bun run --cwd packages/paidotopos test
bun run --cwd packages/paidotopos build
```

## Thumbnails

From this directory, install Playwright Chromium once (`bunx playwright install chromium`). ffmpeg is needed only for MP4 social videos.

```sh
bun run thumbnails                          # all, builds and starts production
bun run thumbnails orbit-study             # one
bun run thumbnails orbit-study other-slug  # several (commas also supported)
bun run thumbnails --missing                # only absent previews
bun run thumbnails orbit-study --video      # light/dark PNG + interaction MP4
```

`--no-build` reuses a current production build. `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` selects a preinstalled Chromium. Captures use an ephemeral signed session, never a production password. They run at 1200×800; no live apps run in gallery cards. PNGs are intentionally static. Missing images render a fallback. Inspect every capture before committing.

## Deployment

Import `hasparus/eclectic` into Vercel. Set Root Directory to `packages/paidotopos`, enable access to files outside the root, framework Next.js, install command `cd ../.. && bun install --frozen-lockfile`, build command `bun run build`. Connect the Git integration for an automatic preview deployment on every PR.

Set `PLAYGROUND_PASSWORD` and an independent 32+ character `AUTH_SECRET` in both Preview and Production. Optionally set `SITE_URL` to the canonical absolute origin; public metadata otherwise uses the request origin so branch previews share correctly. Never commit secrets. See `.env.example`. A production build without secrets fails closed for private content. Development intentionally bypasses the gate.

The repository includes PR lint, type-check, unit and production browser checks. Hosting account connection and secrets must be configured before the first deployment. No private content is published to a static host.

## Privacy

All metadata starts with `public: false`. `hidden` only affects gallery filtering. Public `/p/<slug>` and its preview endpoints validate the public flag; private or unknown names return 404. Raw screenshots and social files remain gated. Public links include OG image, OG video, and Twitter metadata. Before explicitly publishing an owner-approved prototype, capture its video while private, then set its public flag. Build validation requires an MP4 for every public prototype.

`lib/registry.generated.ts` is regenerated by builds and type checks. Discovery validates metadata and required files, then imports each page explicitly so public and private URLs render the same component. Add a new folder, never maintain a manual registry.
